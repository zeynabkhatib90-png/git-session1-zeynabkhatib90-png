## About the project
This is a basic HTML, CSS, and JavaScript website created from the Session 1 starter project. It displays a project overview and updates a status message using JavaScript.

## Technologies
- HTML
- CSS
- JavaScript
- Git and GitHub

## Run locally
Open `index.html` in a web browser. Another option is to run `python -m http.server 8000` in the project folder and visit `http://localhost:8000`.

## Ignore rules
`local.env` and ordinary `*.log` files are ignored. The `important.log` exception keeps the required log tracked. Temporary files in `tmp/` are also ignored.
